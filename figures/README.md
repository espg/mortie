# Review figures for PR #138 — disposable branch

This branch exists only to host the eight before/after divergence figures referenced from the
[PR #138](https://github.com/espg/mortie/pull/138) review thread, because GitHub's comment API
cannot attach images to a comment. Each PNG shows one divergent case as three orthographic globe
views — input geometry, `main`'s cover (`0e35e5a`), and the branch's cover (`1ef27f6`) — over a
near-side row and an antipodal row, so hemisphere-scale covers are fully visible. Nothing here is
source, test, or documentation: the branch carries no code changes, is **never to be merged**, and
can be deleted the moment PR #138 is closed.
