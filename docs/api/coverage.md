# mortie.coverage

Polygon-to-morton coverage. The MOC (multi-order coverage) set algebra over
the covers it produces lives in [mortie.moc](moc.md); the batch coverer,
`polygons_to_morton_mocs`, lives in [mortie.batch](batch.md) (issue #170).
